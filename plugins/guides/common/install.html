{N}Installing and opening {NAME}

{NAME} is one of three QGIS plugins that process a Canadian Lidar mobile mapper job one after the other. All three need the DCS Core plugin, which holds what they share: the job's processing project, the files each stage hands to the next, the look, the header and the window.

StagePluginReadsFinalizes
01PosProThe mapper captures (.clraw or .anpp), base station dataThe trajectory: trajectory.json with SBET and SMRMSG
02AlignProThe captures and PosPro's trajectoryThe Lidar mounting: alignment.json
03CloudProThe captures, the trajectory and the mountingThe point cloud: cloud.json, LAS 1.4, ground grid, report

Requirements

  • QGIS 3.34 or later, including QGIS 4.
  • DCS Core {CORE_VERSION} or later. {NAME} {VERSION} will not start with an older DCS Core: a message bar asks you to update it.

Install from the Canadian Lidar repository

  1. In QGIS open Plugins › Manage and Install Plugins › Settings, press Add… and enter the repository URL https://canadian-lidar.github.io/qgis-plugins/plugins.xml.
  2. Press Reload all Repositories, then install DCS Core first and {NAME} after it.
  3. Restart QGIS. Later versions appear under Upgradeable in the same window; update DCS Core together with the plugins.

Without internet access, use Install from ZIP in the same window with dcs_core-{CORE_VERSION}.zip first, then the {NAME} zip.

Opening {NAME}

  • Plugins › Canadian Lidar › Data Systems › {NAME}, or the {NAME} button on the Plugins toolbar.
  • From another DCS plugin: click the {NAME} box in its header to open {NAME} on the same project.
  • This guide: the ? button in the header, User guide (this version) in the project box, or Help › Plugins › {NAME} user guide. The guide that opens always matches the installed version.
