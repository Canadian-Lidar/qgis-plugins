about=RemixPro makes the files other programs read from the mapper's recordings, on the office PC, and turns the survey boat's SonarView recordings and TidalCal projects into .clraw for the DCS plugins: BeamworX raw files (.bwxraw, one per .clraw, with the survey configuration .xml) for AutoPatch, AutoClean and TrajEdit; Inertial Explorer files (IMR raw IMU in Inertial Explorer's axes, RINEX 3.04 observations of both receivers, GPS ephemeris, a setup note with the lever arm); Qinertia files (generic IMU $qimu, the same RINEX files, a setup note). Open a mapper project folder, a USB copy, an unzipped download or single .clraw / .anpp files; survey lines, navigation recordings and older captures are found from the files' own records. Outputs are made once, in a separate folder (in a DCS project: Processing/<Name>/RemixPro), and again only when the recordings change; the recordings are never modified. The files are the same, byte for byte, as the mapper made before version 2.10. Also runs from the command line (python -m RemixPro.cli). Needs the DCS Core plugin. Menu: Plugins > Canadian Lidar > Data Systems.

changelog=1.2.0 Sonar recordings: the GNSS receiver's files are found beside the recording, in the folders next to it (Rover/, Base/, 02_GNSS_Rover_Base) and inside Emlid's zips (names with a line break included); rover and base told apart; the base's own .LLH never used as the boat's position; .LLH lines taken from GPS time to UTC. Offsets from SonarView's Mount Offset when there is no sonar_offsets.json (TidalCal's vessel table last). Split recordings (-1, -2 ...) converted as one. Details: the recording's own start time, where the position comes from, the GNSS files, each sonar's offsets and their source; the log gives position counts.
    1.1.0 The new DCS header (DCS Core 1.11.0, API 12): the window is always a normal window (no docking, no Window button).
    1.0.1 Start-up: when DCS Core is upgraded while QGIS is running, the message now says to restart QGIS (not to update DCS Core again), and the menu entry stays under Plugins > Canadian Lidar > Data Systems with the other plugins even then (it no longer makes a second Canadian Lidar menu).
    1.0.0 First release (from mapper 2.10.0, which no longer makes these files): BeamworX .bwxraw + survey configuration .xml from survey lines; Inertial Explorer IMR + RINEX + setup note and Qinertia $qimu + RINEX + setup note from survey lines, navigation recordings and Certus logs. Reads mapper project folders, USB copies (hidden and unfinished files ignored, lines still being copied marked incomplete), downloads and single files, older captures included. The writers are the mapper's own: the files are the same, byte for byte, as the mapper made them (checked against its code), apart from the program name RemixPro. Made once, again only when the recordings change; a cancelled or failed conversion leaves nothing half made. Also converts the survey boat's SonarView recordings (.svlz / .svlog) and CLAM TidalCal projects to .clraw (kind sonar) for the DCS plugins, losslessly: every packet kept, one channel per sonar with its own motion, the vehicle data and the Reach RINEX / LLH / PPK files beside them, measured offsets from sonar_offsets.json. Needs DCS Core 1.5.0.
