description=Point cloud georeferencing, cleaning, classification and delivery for the Canadian Lidar mobile mapper: stage 03 of the Data Collection Systems chain (PosPro, AlignPro, CloudPro).
about=CloudPro opens the job's shared processing project, georeferences every Lidar return of the mapper's .clraw captures at its own firing time with the trajectory PosPro published and the mounting AlignPro published (or the mounting recorded in the capture, marked "no calibration"), and gives fast manual and automatic cleaning: a four-quarter layout (Plan with the project grid and a rotatable Inspection Area, Slice for cross-sections and profiles, interactive 3D, automatic filters), an icon tool bar that can float, editing by rectangle, polygon, lasso, brush and above/below a drawn line (reject, accept, select, classify, inside or outside), a Project Properties window (information, geodetics, survey configuration, project files), exact stepping navigation, and 36 automatic filters in groups with live preview (cell statistics, clip, isolated cluster, cloth ground, statistical outliers, snow and rain removal, morphological ground filters, eigenvalue features, wall and reflection detection, height above ground classes, multi-pass moving-object removal, and feature extraction of road markings, curbs, poles, traffic signs, power lines, manhole covers and guardrails). When PosPro or AlignPro publish again, Update georeferencing rebuilds the points and carries every edit over. Publishes LAS 1.4, a ground grid and cloud.json for the job. Needs the DCS Core plugin. Menu: Plugins > Canadian Lidar > Data Collection Systems.

    1.2.2 3D navigation arrows in the top left of the 3D view: click an arrow head to turn the cloud up / down (blue), left / right (red) or clockwise / anticlockwise on the screen (green); hold to keep turning. The Slice view is labelled "Slice" only.
    1.2.1 Top bar: MENU (now holding Project properties) with the PosPro / AlignPro / CloudPro chain beside it, the project button centred. Cell size of the Plan's project grid on the tool bar. Corner arrow on the cycling tool buttons opens their list. Colour scale bar in every view (on / off), and any view's colours can be linked to another view's (scheme and scale). Tune the filters to the sensor precision: XT-32 and Certus error budget, PosPro's SMRMSG standard deviations and the noise measured on the data set the tolerances. Faster and steadier with big jobs: point budgets measured from the machine's own frame times (thinner while moving, a cap for still 3D frames), a memory check before loading a large Inspection Area (estimated from the grids), autosave every 2 minutes, filter groups written atomically.
    1.2.0 Reworked window: Canadian Lidar logo; Menu button (georeference, publish, export, QGIS layers...); Properties window (project information, geodetics, survey configuration with values that can be changed without touching the raw files, project files with points / drive line on-off and select). Four quarters: Plan (the Overview's grid, drive lines and Inspection Area moved into it; right click for Inspection Area properties), Slice (cross-section and profile merged, with its own bar), 3D, and Automatic filters / Lines Classes Info / History. Icon tool bar that can be dragged out: pan hand, one selection button cycling rectangle / polygon / lasso / brush, one above / below line button, ruler, info, action (reject, accept, select, classify, filter) and inside / outside. Point colours per view, plus colour by file. Filter groups and filters chosen from lists with their settings below and "?" help for every filter, group and panel. Seven feature extraction filters from the literature (road markings, curbs, poles, traffic signs, power lines, manhole covers, guardrails), new classes 67-71, and a ready-made Feature extraction group. Every bar and button painted by CloudPro so the Windows / QGIS 4 style cannot turn it white.
    1.1.1 One menu entry: "place the Inspection Area from the map" is now the Pick on map button in the CloudPro window.
    1.1.0 Part of the DCS chain: needs the DCS Core plugin. Opens the job's shared project (Processing/<Name>/<Name>.dcsproj) and works in 03_CloudPro (work/, out/, log/). Georeferences with PosPro's published trajectory (trajectory.json) and AlignPro's published mounting, lever arm and latency (alignment.json), or the recorded mounting marked "no calibration". Update georeferencing after PosPro or AlignPro re-run, keeping every manual and filter edit. Publish writes LAS 1.4 / ground grid to out/ and cloud.json (trajectory and alignment ids used, filters applied, classes, CRS); out of date when PosPro or AlignPro publish again. Chain bar PosPro / AlignPro / CloudPro, relocate a moved job folder, save the QGIS project in the project folder, one log per run, editing lock per job. Look, menus and menu entry from DCS Core. "Lidar" spelling, no third-party product names. Older stand-alone .cloudpro.json projects still open.
